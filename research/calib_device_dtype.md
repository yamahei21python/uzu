# 校正のデバイス・dtype 分離（0.8B）

2026-11-08

## 動機

q512 の bf16 校正（CPU）が f32 校正（GPU）より EN で良く出た（1.34% vs 1.97%）。
しかし **デバイスと dtype が同時に違う**ため、どちらが寄与したか分からない。

T4 は BF16 の行列積を実行できない（`ALG_DOT_BF16_BF16_F32`）ので 2×2 は組めない。

## 設計

q128（CPU f32 が載る条件）で 3 点を比較する。

| 記号 | デバイス | calib dtype | 条件 |
|---|---|---|---|
| A | CPU | float32 | s32 / q128 / d1e-2 / mixed50（既存: EN 2.16% / JA 2.73%） |
| B | CPU | bfloat16 | 同上（新規） |
| C | GPU (T4×2, TP=2) | float32 | 同上（新規） |
| D | GPU | bfloat16 | **不可** |

評価は全条件 `--eval-dtype float32`、100 chunks、dedup コーパス。

## 解析

- device 効果 = C − A
- dtype 効果 = B − A
- seed 幅（EN 0.89pp / JA 0.23pp、d1e-3 での実測）を超えない差は「効果なし」とする

## 予測

| ケース | q512 の 0.63pp の説明 |
|---|---|
| A≈B≈C | 説明できない → q512 固有の要因（メモリ挙動、サンプル数）を追加調査 |
| C < A（GPU が悪い） | デバイス差。以後、比較は同一デバイス内で行う |
| B < A（bf16 が良い） | bf16 校正を既定にする（メモリも減る） |

## 限界

- 結論は q128 のもの。q512 への外挿は仮定
- GPU は TP=2、CPU は 1 デバイス。TP 自体の数値影響は未検証
- A は別レーンで測定済みの値を使う（同一 kit 世代ではない）
