## 第1節【引用】: PPL 言語間比較不能の定量化
PPL は分割粒度に依存。Qwen3.5【引用】 は語彙 248320【引用】 で日本語効率が高いが文字種別 Fertility 差により直接比較不能。
数式: $\text{BPC} = \frac{\text{NLL}_{\text{total}}}{\ln(2【引用】) \cdot n_{\text{chars}}} = \log_{2【引用】}(\text{PPL}) \cdot \text{Fertility}_{\text{char}}$。BPC 換算で分割粒度差が相殺される。

| 文字種 | Fertility (tokens/char)【推定】 | 文字数/tok【推定】 | 特性 (語彙 248320【引用】) |
| :--- | :--- | :--- | :--- |
| ひらがな | 0.75【推定】 | 1.33【推定】 | 助詞 2〜3【推定】 文字で 1【推定】 トークン化 |
| カタカナ | 0.85【推定】 | 1.18【推定】 | 外来語で細分化 |
| 漢字 | 1.15【推定】 | 0.87【推定】 | 常用 1【推定】 トークン、難字分割 |
| 混合日本語 | 0.90【推定】 | 1.11【推定】 | EN 比で文字トークン数 3.75【推定】 倍 |

## 第2節【引用】: 正規化指標の定義と実装
BPC = $(\text{NLL} / \ln(2【引用】)) / n_{\text{chars}}$、BPB = $(\text{NLL} / \ln(2【引用】)) / n_{\text{bytes}}$、bits/token = $\text{NLL} / (\ln(2【引用】) \cdot n_{\text{tokens}}) = \log_{2【引用】}(\text{PPL})$。

| 指標 | 定義式 | 単位 | 比較性 | 特徴 |
| :--- | :--- | :--- | :--- | :--- |
| PPL | $\exp(\text{NLL} / n_{\text{tokens}})$ | なし | 不可 (×) | 粒度依存。同一コーパス限定 |
| bits/token | $\text{NLL} / (\ln(2【引用】) \cdot n_{\text{tokens}})$ | bits/tok | 不可 (×) | 分割バイアス温存 |
| BPC | $(\text{NLL} / \ln(2【引用】)) / n_{\text{chars}}$ | bits/char | 条件付 (△) | 文字長基準。密度差残存 |
| BPB | $(\text{NLL} / \ln(2【引用】)) / n_{\text{bytes}}$ | bits/byte | 最優秀 (◎) | 情報理論的公平性最高 |

既存 `scripts/eval_quantized.py` への BPC 追加提案 (擬似コード 15【引用】 行以内、変更提案のみ):
```python
# scripts/eval_quantized.py への BPC 追加案 (擬似コード)
def eval_norm(model, tok, text):
    enc = tok(text, return_tensors="pt")
    n_tok, n_c, n_b = enc.input_ids.size(1【引用】), len(text), len(text.encode("utf-8【引用】"))
    with torch.no_grad():
        loss = model(**enc, labels=enc.input_ids).loss.item()
    nll = loss * n_tok
    inv_ln2 = 1.0【引用】 / math.log(2.0【引用】)
    bpc = (nll * inv_ln2) / max(1【引用】, n_c)
    bpb = (nll * inv_ln2) / max(1【引用】, n_b)
    return {"ppl": math.exp(loss), "bpc": bpc, "bpb": bpb}
```
